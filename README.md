# MPMC (Magiee Pasta Macroni Corner) - Official Website

A website for **MPMC (Magiee Pasta Macroni Corner)**, a cafe & street food stall located in **Nyay Khand 1st, Indirapuram, Ghaziabad**.

---

## 🌟 Highlights & Features

1. **Brand Identity & Atmosphere**:
   - Modern, appetizing light street-cafe theme with creamy ivory backgrounds, golden amber, and fiery crimson accents.
   - High-definition photography of authentic Maggi, Pastas, and Macaroni.
   - 100% Pure Veg & Fresh Ingredients badges.

2. **The 3 Signature Specialties**:
   - 🍜 **Magiee Corner**: Classic Masala Tadka, Cheese Butter Blast, Peri-Peri Double Cheese, Desi Paneer Tikka, Veggie Delight, Spicy Schezwan.
   - 🍝 **Pasta Corner**: Creamy Alfredo White Sauce, Spicy Arrabiata Red Sauce, Pink Mixed Sauce, Baked Double Cheese, Spicy Peri-Peri Paneer Pasta.
   - 🥘 **Macroni Corner**: Desi Tadka Masala Macroni, Cheese Butter Cream, Tandoori Schezwan, Double Cheese Blast, Makhani Malai Paneer Macroni.

## 🚀 How to Run the Website Locally

### Option 1: Direct Browser Launch
Simply double click on `index.html` in your file explorer, or right-click and choose **Open with > Chrome / Edge / Firefox**.

### Option 2: Using VS Code Live Server or Python HTTP Server
Open PowerShell in this folder and run:
```powershell
python -m http.server 8000
```
Then visit: `http://localhost:8000`

---

## 🛠️ How to Customize Menu Items & Prices

Open `app.js` and locate the `MENU_ITEMS` array near the top of the file:
```javascript
{
    id: 'maggi-1',
    name: 'Classic Masala Tadka Maggi',
    category: 'maggi',
    price: 50,
    originalPrice: 60,
    rating: 4.8,
    spiceLevel: 'Medium',
    description: '...',
    image: '...',
    badge: 'Classic'
}
```
You can edit names, prices, descriptions, or add new items at any time.
